# Snakegame
Classic snake game found on Nokia devices of the past

# Stack used :
- Python
- TKINTER used for GUI

# How the game works:
- Opens a pop up window (GUI)
- Use the arrow keys on keyboard to move left right up and down 
- Locate and collect food which then allows the sname to grow 
- If the snake hits the walls of collides with the body of Snake itself the game will be over. 
- You can use the R/r key or the spacebare key to restart the game 
- Scores are located at the top of the screen and increase with every "food" that is collected. 
-ENJOY the nostalgia of this classic game.
